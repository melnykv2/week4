## Playbooks

| Playbook | Targets | Role run | Purpose |
|---|---|---|---|
| `db.yml` | `dbservers` | `postgres-setup` | Installs/configures PostgreSQL, creates the app DB + user |
| `webservers.yml` | `webservers` | `webserver-setup` | Installs Python 3.12 and nginx |
| `deploy.yml` | `webservers` | `deploy` | Clones the app, configures it, runs migrations, starts it behind nginx |

`webservers.yml` only needs to run once per instance (or after an OS-level change);
`deploy.yml` is the one you re-run on every code update.

## Inventory

`inventory.ini` is **generated by Terraform** — see
`terraform/outputs.tf` and `terraform/inventory.tpl`. Re-run `terraform apply` to
regenerate it after any infrastructure change (new instances, replaced instances,
etc.). 

## Secrets

`group_vars/all.yml` resolves `db_password` and `django_secret_key` at runtime from
AWS SSM Parameter Store (`amazon.aws.ssm_parameter` lookup, `decrypt=true`).
